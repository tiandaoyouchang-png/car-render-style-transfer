# Wondful 3.1.1 本机验收

目标环境：用户提供的 macOS 26.6.2 arm64、Blender 5.1.0。以下为待实机执行项目，本次仅完成源码和离线验证。

## 安装

保存工程，安装 3.1.1 安装 ZIP，启用后确认面板版本。必要时重启 Blender。
若加载旧版本，通过“复制诊断信息”的 addon_path 确认实际目录。不要删除 CLI 的账号配置。

## AGY

1. 选择 Antigravity，检测安装；确认展示真实 agy 路径与版本。
2. 点“Google 登录”。应打开系统终端中的官方 CLI。完成主题、工作区信任等首次设置和浏览器登录。
3. 回插件选择模型，再点“验证登录”。只有真实 CLI 请求成功才显示已验证；验证会使用极少量文本额度。
4. 重启 Blender 后再验证，检查凭据可复用。若仍要求登录，记录当前 AGY Provider 的诊断，而非 Codex Provider 的未知 AGY 字段。
5. 如需兼容内嵌授权，在账号详情选择“插件内授权（兼容）”。只使用本次进程请求的 code，测试提交、取消和新进程复用。不要将授权码写进诊断或发给他人。

## 模型

1. 分别选择 Codex 与 Antigravity，点击“刷新”。模型框应可搜索和选择 CLI 返回的具体 ID。
2. 选择两种不同模型，确认“当前选择”变化。对照 session 的 prompt_profile.agent_model_requested；两种服务的选择应独立保留。
3. 切换模型后，已有 AI 提示词要求先适配；手动初始创意不应被自动覆盖。
4. 点击“默认”后不再传覆盖 ID。不能将 CLI 默认标签解读为已查明底层图像模型。
5. CLI 不支持目录查询或读取失败时，应显示真实错误，并允许在无列表状态输入模型 ID；不得展示虚构模型。

## 提示词

输入或粘贴超过 400 个中文字符且不带换行的段落。收起时约 6 行预览，展开后显示自动换行全文；内容不丢字、不被插入显示换行。
点击“编辑完整提示词”，验证换行、滚动、中文输入、返回、AI 写回与保存重开，确保只有同一份最终提示词。

## 参考图与生图

1. 使用原先报“6 张超过 5 张”的组合，标准模式生成一次。应先整理参考图集，且不会以数量超限误报 OAuth。
2. 查看本轮 reference_bundle.json：Camera 独立；全部原始逻辑参考均有编号与职责；产品只参考造型，环境负责产品打光。
3. 严格模式开启局部修复与多次尝试：首轮最多 3 个输入，修复追加候选图与 Mask 后最多 5 个，不重复追加白模。
4. 无新位图时必须报错，不能导出旧候选、参考图或图集冒充结果。
5. 检查输出比例与主体位置，进入 Compare 检查轮廓、尺度、视角、轮心等。不得自动裁切掩盖漂移。
6. 核对原场景、相机、产品集合、合成节点与工作区恢复；输出保存到选定目录。

图集属于视觉约束，会等比缩放其中的参考；无法保证像素级构图相同。实际改善需要同场景、多轮对照后判断。

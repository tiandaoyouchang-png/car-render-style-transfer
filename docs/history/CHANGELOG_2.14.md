# Wondful AI 渲染器 2.14 · Style Refresh Guard

## 修复：更换风格图后直接渲染可能失效/异常

2.13 允许在旧提示词仍包含上一套风格语义时直接替换风格图并生图。新风格参考和旧文字风格可能互相冲突，导致新风格不生效，极端情况下生成异常空白结果。

2.14 改成强制两阶段流程：

1. 新增、替换、粘贴、删除、清空或调整风格参考图顺序后，立即把当前提示词标记为“风格已过期”。
2. 风格过期期间，主界面显示警告并禁用 `AI 渲染`。
3. 原 `AI 润色` 按钮会显示为 `重新生成提示词`。
4. 重新生成时，明确要求 Provider 丢弃旧提示词中的色调、灯光、材质、摄影、氛围和后期风格描述，仅保留主体、场景功能和构图意图，再根据当前最新风格图重新构建风格语义。
5. 只有提示词生成成功且生成期间风格参考没有再次变化，才解除渲染锁定。
6. 使用 revision guard 防止“AI 正在生成提示词时又换了风格图”造成旧结果误判为已同步。

推荐流程：`换风格图 → 重新生成提示词 → 可手动修改 → AI 渲染`。

兼容旧工程：如果升级到 2.14 时 `.blend` 里已经存在风格参考图，但这些参考尚未经过 2.14 的同步流程，也会自动进入“风格未同步”状态，必须先重新生成提示词。

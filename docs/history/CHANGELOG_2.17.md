# Wondful AI 渲染器 2.17

## Single Prompt Editor

- 提示词不再使用带滚动条、加减按钮和逐行边框的 `UIList` 作为主编辑器。
- Blender 5.2+ 使用原生 `UILayout.textbox`：一个真正的多行输入框直接绑定唯一 `prompt` 字符串。
- 1–5 行按内容显示；超过 5 行默认折叠到 5 行，可展开全文。
- Blender 4.3–5.1 因官方 API 尚无原生多行 RNA textbox，兼容路径改为一个外框内的无独立边框行编辑，不再出现截图中的多个独立小输入框/滚动条/加减按钮。
- AI 润色 / 重新生成提示词仍直接覆盖同一个 canonical Prompt，之后可继续手动修改。

## Inline Action Progress

- AI 润色运行时，原按钮位置直接变为进度条：`AI 润色 · Provider · 42%`。
- AI 渲染运行时，原按钮位置直接变为进度条：`AI 渲染 · Provider · 67%`。
- 完成或失败后恢复正常操作按钮。
- 已登录状态下不再在顶部重复显示“润色中/渲染中”的任务进度；顶部只保留相机与必要错误信息。
- 登录任务仍在顶部显示登录进度，因为它没有对应的工作流动作按钮。

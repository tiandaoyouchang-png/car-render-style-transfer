# 3.0.2 · Reference Instructions

## UI 工作流

- 参考图区域移动到 AI 润色 / 重新生成提示词按钮上方。
- 主流程变为：提示词 → 参考图及参考重点 → AI 润色/重新生成提示词 → AI 渲染。
- 每张产品 / 人物 / 风格参考图右侧新增“参考内容”输入框。

## 每图参考重点

用户可以逐图告诉 AI 这张图具体参考什么，例如：

- 产品图：只参考前脸造型 / 只参考车漆材质 / 只参考轮毂结构。
- 人物图：只参考人脸 / 只参考发型 / 只参考服装。
- 风格图：只参考灯光和色调 / 只参考材质表现 / 只参考摄影与后期。

未填写时继续沿用该类参考图的默认职责。填写后，用户指定重点会作为该图片的实际参考范围，避免模型无差别迁移整张参考图。

## Prompt / Render 链路

- AI 提示词生成阶段会把每张参考图的“参考内容”与对应 Reference 编号一起发送给 Provider。
- 风格分析独立阶段也读取每张风格图的参考重点。
- 最终 AI 渲染 Prompt 同样携带逐图参考重点，且不改变 Blender Structure Packet 的结构优先级。
- 修改风格参考图的“参考内容”会把风格 Prompt 标记为待重新生成。
- Session metadata 新增 `reference_instructions`，便于确认每次实际使用的逐图指令。

# 3.0.8 · Environment Lighting

基线：已交付的 Wondful AI Renderer 3.0.7。

本轮按用户要求修正参考图职责：产品打光来自环境参考，产品图只提供造型识别。

- 产品主参考和辅助参考都仅提取身份与造型识别细节，取消产品图材质、配色、灯光、高光、反射、阴影和背景的默认贡献。
- 环境主参考决定产品受光方向、色温、软硬、明暗、环境反射和接触阴影；辅助环境图补充兼容信息。产品应在该环境中重新受光。
- 无环境图时使用文字中的灯光要求；未指定则采用自然中性环境光，不能改用产品图的光照。
- 逐图“参考什么”由替换默认规则改为在类别边界内收窄范围。填写产品灯光 / 材质参考的旧说明不能扩大产品图职责。
- 同一规则贯穿环境独立分析、润色系统提示词、逐图映射、最终生成包装和 Codex / AGY Provider。
- “产品”入口改为“产品造型”；“风格”改为“环境／风格”，保留原集合字段和已有图片。
- 增加隐藏职责版本字段。旧工程的 AI 润色内容须重新生成一次，再标记职责迁移完成；手动草稿不被自动重写。
- 保留 Blender 的构图 / 几何权威，不改变结构图顺序、FAST / STANDARD / STRICT 调用策略或对比功能。

验证：新增 9 项针对性回归，累计 56 项通过；20 个插件模块及工程全部 Python 文件 py_compile / AST 通过。真实 Blender GUI 和真实产品受光效果待实机验证。

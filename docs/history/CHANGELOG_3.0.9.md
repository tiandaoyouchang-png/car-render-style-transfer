# 3.0.9 更新记录

基线：3.0.8。重点是输入体验与白模构图一致性。

## 提示词

- 修复“Blender 未创建提示词编辑窗口”：使用当前编辑区的 Text Editor，并提供“完成编辑 · 返回渲染”。
- 默认提供真实提示词输入框；用户先写创意，再 AI 润色，仍可继续修改。
- 润色移除 Camera Base 捕获依赖；只发送文字和实际参考图，修正对应编号。
- 环境更新时优先保留最新手动文字；清空输入也生效；未手改时使用原始创意重新生成风格。
- 保存工程前同步最后输入并恢复原编辑区；返回时保留原 Text Editor 的用户文档和显示选项。

## 构图

- 相机捕获使用完整画布，关闭边框裁切并恢复用户设置；捕获尺寸异常时停止提交。
- 结构图统一尺寸与像素坐标；较小数据 Pass 保持相机显示比例，严格模式用原生完整尺寸。
- 不再自动居中裁切 AI 结果；增加本地比例检查与结果提示。
- 两个 Provider 的验收都返回独立观察的主体包围框 / 可信度；用归一化几何偏差约束评分，明确为视觉估计。
- 严格模式对比例错误跳过远程评分并从白模重试；对局部偏移使用目标与当前位置的联合修复 Mask。
- 原生包围框右 / 下边界计入最后一像素；轮部件锚点改为求值几何包围盒中心估计，避免多个导入物体共用原点。
- Compare 增加白模产品轮廓叠加；差异模式明确包含外观差异；显示结构图降级状态。

## 保留与验证

产品图只提供造型，环境参考决定产品照明。保留单一 Prompt、Provider 路由、产品集合递归识别、独立 Compare 工作区、FAST / STANDARD 单次远程生图与输出快照。

80 项离线回归通过；真实 Blender 安装 / GUI / Pass 和真实 AI 生图待实机验证。没有宣称像素级对齐保证或实测提速比例。

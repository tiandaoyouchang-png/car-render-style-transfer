# 3.1.1 更新记录

## 修复

- 引入参考图容量规划与带逻辑编号的参考图集，避免白模 + 多张结构图 + 外观图直接超过 5 个路径。
- 在严格模式提交首轮前，为后续候选底图与局部修复 Mask 预留两个输入；相同路径去重，不重复追加白模。
- AGY 图集清单映射到本轮暂存路径，防止原图与暂存副本被同时提交。
- 参考图数量和普通工具失败不再误报为 OAuth 能力缺失；没有新位图时继续拒绝复用旧候选或参考图。
- AGY 生图请求增加“首步只调用 generate_image”约束；若首轮未调用生图工具而被非交互确认拦截，只安全重试一次，避免重复消耗已发出的生图请求。
- AGY 位图回收支持完整 stream-json 事件、嵌套 brain/.tempmediaStorage、file:// 路径和带空格路径，避免工具已生成但插件漏读。
- AGY 返回 429 / RESOURCE_EXHAUSTED 时显示明确的容量耗尽与预计恢复时间，不再误导为登录失效；避免反复重新授权消耗请求。
- AGY 主流程改为官方终端登录后回插件验证；共用稳定工作目录，检查 macOS 终端启动结果，保留选定 CLI 的运行环境。
- 验证请求传递用户选择的模型；授权后出现配额、模型或网络问题时保留实际错误。
- 插件内兼容登录桥接不再提前显示被输出分块截断的 OAuth URL。
- 提示词展开属性接入主面板；中文长段落自动换行，完整编辑器保持原有内容与返回机制。

## 新增

- 主面板具体推理模型列表、刷新与恢复 CLI 默认选择。
- Codex 官方 app-server 模型目录查询与分页；AGY 官方本地模型目录查询。
- 诊断中记录实际 CLI 路径、插件路径、模型目录状态和参考容量。
- AI 渲染按 Provider 生成独立结果：Codex 4 张，Antigravity 2 张；每张结果单独调用内置生图工具并导出，面板预览其中最佳图。
- Provider 返回近似画幅时，最终结果按比例缩放并透明留边到 Blender Camera Output；不裁切、不拉伸，并将 JPEG 内容规范化为真实 PNG。
- 26 项回归测试；总计 144 项离线测试通过。

## 兼容性

- 基线为 3.1.0，保留 3.0.9 / 3.1.0 的构图、产品造型与环境打光职责、单一提示词、输出目录、Compare、提示词适配与缓存策略。
- Render Director 规则包仍为 1.0.0，其内容及哈希未更改。
- 最低 Blender 声明仍为 4.3；已在本机 Blender 5.1 / AGY 1.1.27、当前 Google Keychain 会话完成单图真实生图链路验收，Provider-specific 多图正式渲染仍由用户场景触发。
## 3.1.1 maintenance

- 打开或切换 `.blend` 后，如果上一次异步任务在“读取模型／登录／润色／渲染”期间被中断，且后台任务锁已释放，自动清理持久化的忙碌状态，避免所有按钮永久置灰。
- 为降低 Antigravity 生图容量压力，AGY 每轮输出从 4 张调整为 2 张；Codex 仍保持每轮 4 张。
- 每张候选图完成后立即进行比例适配并导出；如果后续候选图遇到 429 或其他生图失败，已经导出的结果会保留，并在面板中显示已完成数量与 `x/y` 进度。

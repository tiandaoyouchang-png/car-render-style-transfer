# Wondful AI 渲染器 2.18

## Style Reference Refresh Fix

本版专门修复“第一次上传的风格图一直生效，换图后仍然读取旧风格”的问题。

### 根因

1. 2.17 的风格“文件”操作实际上是追加图片；而提示词规则又把第一张风格图固定为主风格，因此首次上传图会长期保持最高风格权重。
2. 风格图变化后重新 AI 润色时，2.17 会把上一轮已经包含旧风格的完整 AI Prompt 再次作为“用户原始创意需求”输入，旧风格语义会持续回灌。
3. 风格同步状态只依赖 revision，不校验图片实际字节；同一路径覆盖新图片时可能被错误视为已同步。
4. Blender `check_existing=True` 可能复用同路径 Image datablock，需要显式 reload。

### 修复

- 风格区的“文件/粘贴”现在定义为“替换当前风格集合”，不会再把新风格追加在第一次风格图后面。
- 风格区有旧图时按钮明确显示“换图 / 替换粘贴”。
- UI 显示“当前主风格”，方便确认真正参与生成的第一风格参考。
- 增加 SHA-256 风格指纹：路径相同但图片内容变化也会触发重新生成提示词。
- AI 渲染前再次校验当前风格指纹与 Prompt 同步指纹，不一致则阻止生图。
- 风格变更后的“重新生成提示词”改为两段式：先只读取当前风格图生成独立风格摘要，再把该摘要作为本轮唯一风格依据写入最终 Prompt，避免旧 Prompt 风格回灌。
- 增加隐藏 `prompt_source`，避免后续风格切换反复把上一轮 AI 风格描述当成用户原始需求。
- 替换同路径图片时主动 `image.reload()`，避免 Blender 图片缓存造成预览/引用滞后。
- 每个成功 Session 元数据记录实际参考图路径、大小和 SHA-256，便于确认 Provider 真正收到的是哪张图。
- 保持 Reference 顺序为 Camera → Product → Person → Style，与 Prompt 中的 Reference 编号严格一致。

### 正确流程

更换风格图 → Prompt 标记过期 → 重新生成提示词 → 当前新风格写入 Prompt → AI 渲染。

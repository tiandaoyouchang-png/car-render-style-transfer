## 具体修复

1. 旧 Text Editor 的单向同步会把 canonical Prompt 的 AI 新值覆盖回旧文本，改为变更来源感知的双向同步。
2. 旧版共用 `Wondful Prompt` 和场景名称，重开清空文本且场景改名后可能失联；改为每场景独立的运行时绑定，不占用用户同名 Text。
3. AI 润色期间发生手动输入时不覆盖用户内容。生成建议另存，风格同步状态不会被误标为完成。
4. 不再逐键重建 legacy prompt_lines。textbox 参数不兼容时回退到整段 Text Editor，不让面板整体失效。
5. 移除 3 个含 RNA Property 声明模块的延迟注解，确保属性工厂表达式在类声明时求值；覆盖属性声明模拟检查。
6. CLI 显式入口保持优先；保留软链接所在目录来找到 `/usr/bin/env node` 等同级运行时。发现不执行 shell 初始化脚本。
7. AGY 解析兼容 JSON / NDJSON、终端色码与前置日志；SUCCESS 与错误字段冲突不算成功。`oauth` / `keyring` 字样或 403 策略拒绝不再单独触发未登录。
8. AGY `--version` 失败仍允许登录探测。SUCCESS + 无关 denied_actions 的旧修复保留。
9. AGY Edit Base / Mask 已在 Reference 中时复用附件；工具 ACTIVE / DONE 事件按 step 去重计数。
10. 产物检测排除原始输入与暂存副本，并对会话内预存图片做生成前快照。检查位图头部，不接受伪装为 png 的文字文件；最终解码仍由 Blender 图像流程完成。
11. 清除 Codex 上个子任务的 last-message 文件，避免空响应复用旧润色文本。
12. 回传结果使用提交时尺寸、相机、输出目录和参考信息，防止等待期间改场景导致错误裁切 / 导出。
13. 增加任务入口互斥、所属任务释放锁和模态收尾错误处理；关闭任务窗口后，后台请求结束前仍保持互斥。没有新增“终止远程生成”能力。
14. 增加本地准备和端到端耗时，保留远程生图 / 审计耗时。

## 验证边界

自动回归不包含真实 Blender GUI、真实 CLI OAuth、生图质量或端到端速度基准。不能承诺十几分钟已缩短到某个数值。现有 EEVEE 原生 Pass、像素对齐与 STRICT 纠偏仍需实机验证。

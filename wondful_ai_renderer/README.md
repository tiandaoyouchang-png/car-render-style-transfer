# Wondful AI 渲染器 3.1.3

> 3.1.3 新增真实 TypeSafe / Jev 语义层：Semantic Part、Material Resolver、Logo/字标身份资产保护、修改范围判断与批量参考图分类；未配置 `TYPESAFE_API_KEY` 时自动使用本地规则回退。详见 `CHANGELOG_3.1.3.md`。


基于 3.1.0 源码的修复版。处理参考图超限、AGY 登录入口、具体模型选择、长提示词阅读，以及 AGY 生图工具调用与位图回收问题。

## 安装与使用

1. 保存当前 `.blend`，退出 Blender。重新打开后，在偏好设置中停用旧插件，通过“从磁盘安装”安装 `Wondful-AI-Renderer-Blender-3.1.1.zip`，然后启用。必要时再重启一次 Blender。
2. 确认面板显示 **3.1.1**。`Source.zip` 是源码包，不用于直接安装。
3. 选择 Codex 或 Antigravity，点击模型框旁的“刷新”。列表来自当前电脑上的官方 CLI；选择具体 ID 后，“当前选择”显示该值。没有列表时可以输入官方模型 ID；“默认”清除覆盖值。
4. AGY 首次使用先点“Google 登录”，在官方终端完成初始化和浏览器授权，再回插件点“验证登录”。验证使用当前选择的推理模型，并发起一次极短文本请求。
5. 输入创意需求、设置参考图与说明，再点 AI 润色。需要阅读长文时点“展开全文”；“编辑完整提示词”打开支持中文、换行、滚动的 Text Editor，完成后点返回。AI 润色后仍可编辑同一份文本。
6. 选择相机、产品集合与输出位置，开始渲染。Codex 每次独立生成并导出 4 张，Antigravity 每次独立生成并导出 2 张；原来导致 6 张超限的参考组合可以保留，插件在提交前自动整理。

不需要重新删除 CLI 的登录配置。若面板仍显示旧版本，用“复制诊断信息”中的 `addon_path` 确认实际加载的插件路径。

## 本版改动

- **生图输入容量**：白模始终作为独立完整底图；超额结构图、产品图、人物图、环境图按职责整理成带 R 编号的图集。全部逻辑参考保留。Codex 单次提交不超过 5 个独立路径，Antigravity 单次提交不超过 3 个；严格模式按当前 Provider 预留修复输入。
- **错误分类**：参考图数量、参数、配额和输出文件问题保留实际原因，不再自动归为 OAuth 或 ImageGen 能力缺失。此次用户日志明确报告 6 个路径超过 5 个上限。
- **AGY 登录**：主界面显示“Google 登录”和“验证登录”。终端与验证使用同一持久工作目录，避免验证每次换临时目录；macOS 终端启动失败会明确报错。旧插件内授权桥接保留在账号详情中供兼容使用。
- **模型选择**：Codex 通过 app-server 的 `model/list` 查询，AGY 通过 `agy models` 查询。刷新不启动模型对话。两种 Provider 分别保存选择，实际请求使用所选 ID，不做跨模型静默回退。
- **提示词**：可展开与收起，中文与英文按面板宽度换行。不支持内嵌多行输入的 Blender 使用“输入框 + 全文预览 + 完整编辑器”；预览不会把换行或裁切写回提示词。极长内容的面板预览最多 120 行，完整编辑器保留全部内容。
- **诊断**：增加真实 CLI 路径、插件加载位置、模型列表状态、登录阶段详情与参考图容量记录。

“推理模型”用于润色、构图检查和指挥生图工具。底层图像模型由 CLI 内置工具管理，本插件没有虚构图像模型切换选项；未报告的实际图像模型仍记为未知。模型列表反映 CLI 返回的目录，不能保证账户额度、区域和所有工具权限都可用。

## 保留的工作流

产品参考只决定身份和造型；环境参考决定产品受光、反射、阴影与场景氛围。没有环境图时按用户文字与中性环境处理。

白模相机是构图权威，产品集合及子集合是结构来源。快速与标准模式按 Provider 独立调用生图：Codex 4 次，Antigravity 2 次；严格模式对每张结果按设置验收并修复。Blender 预览显示最佳结果，所有候选图均写入输出目录。若 Provider 返回近似比例，插件会等比缩放并透明留边到 Camera Output，不裁切、不拉伸。保留 Camera Base、结构图、原位编辑、Mask 修复、比例检查与 Compare 对比。

严格模式如果对齐失败，仍会按现有设置对单张候选图进行修复重试，因此实际远程调用次数可能高于最终导出张数；最终输出数量仍为 Codex 4 张、Antigravity 2 张。每张候选图完成后会立即完成比例适配并写入输出目录；如果后续请求遇到 429，已经完成的文件不会被丢弃，面板会显示“已完成并导出 x/y 张”。

切换 Provider 或推理模型后，已有 AI 提示词需先适配当前引擎；不会静默覆盖手动输入。3.1.0 的 Render Director 1.0.0 规则包保持不变。

图集解决的是输入容量。图集中各格会等比缩放，不能代替原生 ControlNet 或保证像素级对齐；白模底图本身不拼贴、不变形。画质和构图改善仍需同场景生图对比。
